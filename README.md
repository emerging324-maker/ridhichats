# Ridhi Chats POS

Billing app for Ridhi Chats (Pure Jain Veg, Katpadi, Vellore).

- Open `index.html` through the hosted https link in Chrome; installable as an app.
- Bills and expenses are stored in Google Sheets (`RidhiChats_AppScript.gs`).
- Printer: POSiFLOW PSF210 (58 mm Bluetooth).
- User guide: `Ridhi_Chats_POS_User_Manual.pdf`.
